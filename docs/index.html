Comment s'abonner dans Outlook

  1. Ouvrez Outlook sur le web ou dans l'application
  2. Calendrier → Ajouter un calendrier → S'abonner à partir du web
  3. Collez l'URL ci-dessus et donnez un nom au calendrier
  4. Cliquez sur Importer

Outlook rafraîchit les abonnements ICS toutes les ~3 heures automatiquement.
